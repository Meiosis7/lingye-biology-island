# 灵野图鉴 · 生命群岛

面向初中生物的原创像素冒险：在五片生态栖息地里认识动植物类群，通过观察特征收录生灵、完成研究图鉴。

## 直接游玩

前往 [Releases 下载成品](https://github.com/Meiosis7/lingye-biology-island/releases/latest)，下载 `lingye-offline-v2.1.0.html`，用 Chrome、Edge 或 Safari 打开。不需要安装、不依赖联网服务。

完整 ZIP 包另含可编辑源码、美术素材和使用说明。仓库为私有时，需要登录有访问权限的 GitHub 账号才能下载；离线 HTML 可独立使用。

## v2.1：研究员岑叶

- 重新适配的精细像素研究员：叶徽探险帽、浅色外套、绿色内衫与观察背包。
- 四个朝向与正面迈步帧，依据移动方向自动转身；侧面和背面配合步伐起伏。
- 地图中人物尺寸加大，增加落地阴影和轻微待机动作。
- 点击人物打开角色档案，查看正面、侧面和背面形象。
- 兼容已有游戏存档。

## 游戏内容

16 种原创生灵：5 个植物类群、6 个无脊椎动物类群、5 个脊椎动物类群。48 道观察题，包含特征辨认、训练、错题复习、伙伴升级与三卷研究徽章。

点击地图地点移动，点击“探索”或按空格遭遇生灵。答对三个特征即可收录，误判三次结束本次观察。方向键 / WASD 可以切换地区。

进度自动保存在当前浏览器。研究手册支持 JSON 存档导入、导出。不同浏览器及在线/离线版本的进度不会自动互通。

## 本地维护

需要 Node.js；默认预览脚本还需要 Python 3。

```sh
npm ci
npm test
npm run build
npm run dev
```

打开 `http://127.0.0.1:4173/`。构建输出位于 `dist/`，单文件离线版位于 `成品/`。

```sh
python3 scripts/package-release.py
```

该命令重新构建并生成可分发的完整 ZIP 包，明确打包本项目文件，不包含同目录中其他独立项目。

## 文件说明

- `src/data.js`：课程知识、生灵命名与设计、生态区数据。
- `src/core.js`：收录、奖励、存档校验与朝向规则。
- `src/game.js`：地图、问答、角色档案、图鉴和训练交互。
- `src/style.css`：响应式界面与像素帧动画。
- `assets/lingye/`：地图、生灵图集、研究员图集。
- `docs/researcher-design.md`：新角色设计与素材说明。
- `tests/`：规则和交互流程测试。

美术由 AI 辅助生成，角色和能力是艺术拟人化。真实生物知识以图鉴特征卡为准。教学类群沿用初中常见传统表述，不意味着各类群处于同一分类等级或涵盖全部生物。参考资料列于游戏内的“设计与知识说明”。
