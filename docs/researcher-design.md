# 岑叶 · 野外研究员

## 设计目标

替换早期只有几个色块的研究员小人。角色拥有叶徽米白探险帽、深蓝短发、浅色外套、绿色内衫、深色短裤、耐磨靴与叶徽背包。衣物分层和深色轮廓匹配像素生态地图，地图中的可见人物高度约为原来的两倍。

名字“岑叶”分别对应林木山地与植物观察线索。点击人物打开角色档案，可查看大尺寸正面像、四方向形象和装备说明。

## 最终素材与动作

最终素材：`assets/lingye/researcher-sheet.png`，1774 × 887 RGBA PNG，有真实透明背景。

原始来源为本工作区既有生物游戏素材 `翠野生物志-Godot/assets/emerald/characters.png`，仅复制这一张图集，未修改该独立项目。

图集为四列两行。第一行依次为正面、背面、左侧、右侧；第二行前两格为正面交替迈步帧，其余格是未在本次角色中使用的 NPC。以 CSS 取帧，保留原始 PNG 不进行图像重绘或裁切。

移动方向由起点到终点的主要位移决定。正面行走循环切换迈步帧与站立帧，侧面和背面配合轻微步伐起伏，到达后回到对应朝向的静止帧。减少动态效果偏好会关闭这些动画。

## 生成尝试记录

曾使用内置 image_gen 两次尝试生成全新四方向四帧角色图集，两次均因网络错误失败，没有产出任何图像。因此最终没有把既有素材说成这两次生成的成果，也没有转用需要 API 密钥的付费生成路径。

生成尝试提示词：高品质 16-bit top-down pixel RPG field researcher；透明背景；固定四行四列；同一年轻研究员；叶徽米白帽、栗色短发、青绿外套、象牙白工具背心、焦橙领巾、橄榄绿采样背包、卷垫与蓝绿色采样瓶、棕靴；三头身；精细衣物阴影和清楚像素簇；四方向四帧，每格人物比例和脚底基线一致；无文字、无场景、无既有 IP。
